制定日：2026年10月27日（版：2026-10-27）

かるわか（以下「運営者」）は、作業時間記録ソフト「WorkMonitor」と、そのアカウント・クラウド同期・ウェブサイト（以下あわせて「本サービス」）における利用者の情報の取り扱いを、次のとおり定めます。

要点
・作業の記録は基本的にあなたの PC の中だけに保存されます。
・ログインして同期した記録は、送る前に PC 上で暗号化されます。運営者は中身（アプリ名や時間）を読めません。
・ウィンドウのタイトル（開いているファイル名やページ名）は送りません。
・広告や行動分析のための情報収集はしていません。情報を販売することもありません。

1. 運営者とお問い合わせ先

運営者：かるわか
お問い合わせ：GitHub の Issues（Issues は公開されるため、個人情報は書かないでください）

2. 取り扱う情報

(1) PC の中だけに保存する情報（運営者には送られません）

アプリは、キーボードやマウスを操作している間、前面にあるアプリの名前（実行ファイル名）とウィンドウのタイトル、時刻を記録し、PC の %APPDATA%\WorkMonitor に保存します。設定や、これまでに使ったアプリの一覧も同じ場所に保存します。これらは、利用者が同期をオンにしてもサーバーには送りません（同期するのは次の (2) の情報だけです）。

(2) アカウントを作成・同期したときに運営者のサーバーに保存する情報

(3) ウェブサイトの利用で発生する情報

  • ウェブサイトは GitHub Pages で配信しています。閲覧すると、GitHub が IP アドレスなどのアクセス記録を取得することがあります。
  • グラフ表示などのプログラムを jsDelivr・cdnjs（Cloudflare）から読み込むため、これらのサービスに IP アドレスなどが送られます。
  • 最新版の情報を表示するために、ブラウザから GitHub の API に問い合わせます。
  • ブラウザには、ログイン状態、テーマの選択、（「この端末で記憶する」を選んだ場合）暗号鍵を保存します。鍵は取り出せない形で保存し、ログアウトすると消えます。広告や行動追跡のための Cookie は使っていません。

(4) アプリが外部と通信するその他の場合

  • アップデート確認（オンの場合）：1日に1回、GitHub に最新版の番号を問い合わせます。
  • Discord 連携（オンの場合）：PC 内で起動している Discord アプリに、作業中か休憩中かと作業時間（設定によりアプリ名）を渡します。これらは Discord のプロフィールに表示され、Discord の利用者から見える場合があります。Discord での取り扱いは Discord のプライバシーポリシーに従います。

3. 利用目的

取り扱う情報は、次の目的にだけ使います。

  1. アカウントの作成・ログイン・パスワード再設定など、本サービスを提供するため
  2. 記録を同期し、アプリとウェブサイトで表示するため
  3. お問い合わせに対応するため
  4. 不正利用を防ぎ、障害や不具合を調査・修正するため
  5. 利用規約や本ポリシーの変更など、重要なお知らせをするため

4. 第三者への提供

運営者は、次の場合を除き、利用者の情報を第三者に提供しません。

  1. 利用者本人の同意がある場合
  2. 法令に基づく場合
  3. 人の生命・身体・財産を守るために必要で、本人の同意を得ることが難しい場合

5. 外部サービスの利用（取り扱いの委託）

本サービスは、次の外部サービスを使って運営しています。これらの事業者は、それぞれのプライバシーポリシーに従って情報を取り扱います。

6. 安全管理

  • 同期する記録と設定は、送る前に AES-256-GCM で暗号化します（エンドツーエンド暗号化）。鍵はパスワードから PBKDF2-HMAC-SHA256（60万回）で作った鍵で保護し、運営者のサーバーにはパスワードも鍵も送りません。
  • 通信は TLS 1.2 以上で暗号化し、サーバー証明書を検証します。
  • データベースは、本人しか読み書きできないようにアクセスを制限しています。
  • PC に保存するログイン情報と鍵は、Windows の機能（DPAPI）で暗号化しています。

7. 保存期間と削除

  • サーバーの情報は、アカウントを削除するまで保存します。
  • 利用者は、ウェブサイトの「記録を見る」ページ、またはアプリの「設定 → アカウント」から、いつでもアカウントを削除できます。削除すると、アカウント・暗号化した記録・鍵の保管情報・同意の記録がすぐに削除されます。ただし、サービス事業者のバックアップや通信記録からは、完全に消えるまで一定の期間がかかる場合があります。
  • PC の中の記録は、アプリの「記録フォルダを開く」から開くフォルダを削除すると消えます。

8. 利用者の権利

利用者は、自分の情報について、開示・訂正・利用停止・削除を求めることができます。記録の確認と削除は上記の方法でご自身で行えます。そのほかのご依頼は、お問い合わせ先までご連絡ください。なお、暗号化した記録の中身は運営者も読めないため、運営者から中身を開示することはできません。

9. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更する場合は、変更後の内容をウェブサイトで告知します。取り扱う情報や目的が大きく変わるときは、アプリまたはウェブサイトで改めて同意をお願いします。
