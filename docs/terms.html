利用規約

制定日：2026年10月27日（版：2026-10-27）

この利用規約（以下「本規約」）は、かるわか（以下「運営者」）が提供する作業時間記録ソフト「WorkMonitor」と、そのアカウント・クラウド同期・ウェブサイト（以下あわせて「本サービス」）の利用条件を定めるものです。本サービスを利用する方（以下「利用者」）は、本規約とプライバシーポリシーに同意したうえで本サービスを利用するものとします。

第1条（適用）

  1. 本規約は、本サービスの利用に関する運営者と利用者との間のすべての関係に適用されます。
  2. アプリ（WorkMonitor 本体）のプログラムは MIT ライセンスで公開しています。プログラムの利用・改変・再配布の条件は MIT ライセンスに従います。本規約は主に、アカウントとクラウド同期・ウェブサイトの利用に適用されます。
  3. 年齢による利用の制限はありません。未成年の方は、必要に応じて保護者の方と本規約の内容を確認してください。

第2条（アカウント）

  1. 利用者は、本規約に同意し、メールアドレスとパスワードを登録することでアカウントを作成できます。アプリの記録はアカウントがなくても使えます。
  2. 利用者は、自分のメールアドレスとパスワードを適切に管理するものとします。アカウントを使って行われた操作は、その利用者が行ったものとみなします。
  3. クラウドに同期する記録は、パスワードから作る鍵で暗号化されます（エンドツーエンド暗号化）。運営者は利用者のパスワードや鍵を知ることができないため、パスワードを忘れて再設定した場合、クラウドに保存されていた記録は復元できません。利用者はこの仕組みを理解したうえで利用するものとします（PC に残っている記録から送り直すことはできます）。
  4. 利用者は、いつでもウェブサイトまたはアプリからアカウントを削除できます。削除すると、クラウドに保存された記録・鍵・同意の記録も削除され、元に戻せません。

第3条（料金）

本サービスは無料で提供しています。将来、有料の機能を設ける場合は、事前にウェブサイトでお知らせし、利用者が同意しない限り料金は発生しません。

第4条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 他人のメールアドレスを使ってアカウントを作成する行為、他人のアカウントを不正に使う行為
  3. 本サービスのサーバーやネットワークに過度な負荷をかける行為、不正にアクセスする行為、その他運用を妨げる行為
  4. 本人の同意なく、他人の PC の利用状況を記録・監視する目的で本サービスを使う行為
  5. 本サービスの不具合を悪用する行為
  6. その他、運営者が不適切と判断する行為

第5条（利用の停止・アカウントの削除）

運営者は、利用者が本規約に違反した場合、またはその疑いがある場合、事前の通知なくアカウントの利用を停止し、または削除できるものとします。

第6条（本サービスの変更・中断・終了）

  1. 運営者は、利用者に事前に通知することなく、本サービスの内容を変更し、または提供を一時的に中断できるものとします。
  2. 運営者は、ウェブサイトで告知したうえで、本サービス（アカウント・クラウド同期）の提供を終了できるものとします。終了する場合は、可能な限り事前に告知します。終了後も、アプリと PC 内の記録は引き続き使えます。

第7条（保証の否認・免責）

  1. 本サービスは「現状のまま」提供されます。運営者は、本サービスに不具合がないこと、記録される作業時間が正確であること、特定の目的（勤怠管理や作業時間の証明など）に適していることを保証しません。
  2. 運営者は、通信の障害、機器の故障、外部サービス（Supabase、GitHub など）の障害、パスワードの紛失その他の理由による記録の消失について、責任を負わないものとします。大切な記録は、利用者自身で PC の記録フォルダのバックアップを取ってください。
  3. 前2項は、運営者に故意または重大な過失がある場合には適用しません。運営者が損害賠償責任を負う場合でも、その範囲は、運営者の故意または重大な過失による場合を除き、利用者に現実に生じた通常の損害に限られるものとします。

第8条（本規約の変更）

  1. 運営者は、必要に応じて本規約を変更できます。変更する場合は、変更後の内容と効力が生じる日をウェブサイトで告知します。
  2. 利用者の権利や義務に重要な影響がある変更をしたときは、アプリまたはウェブサイトで改めて同意をお願いします。

第9条（お問い合わせ）

本サービスに関するお問い合わせは、GitHub の Issues で受け付けます（投稿には GitHub アカウントが必要です。Issues は公開されるため、メールアドレスなどの個人情報は書かないでください）。

第10条（準拠法・裁判管轄）

本規約は日本法に従って解釈されます。本サービスに関して紛争が生じた場合は、日本の裁判所を管轄裁判所とします。
