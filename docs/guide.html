使い方ガイド

WorkMonitor は、キーボードやマウスを操作している時間だけを「作業時間」として記録する、Windows 用のアプリです。このページでは、インストールから MOD まで、すべての機能の使い方を説明します。

⬇️
まずは入れるインストールと最初の設定
⏱️
数え方を知るどの時間が作業になるか
☁️
スマホでも見るアカウントと同期
🧩
機能を足すMOD ストアの使い方

1インストール

Windows 10 / 11 で使えます。ダウンロードから、次のどちらかを選んでください。中身は同じです。

種類向いている人入れ方
インストーラー（おすすめ）
WorkMonitor-Setup.exe		ふつうに使いたい人ダウンロードして開き、画面の案内に沿って進めます。管理者の権限は要りません。スタートメニューに「WorkMonitor」が入ります。
ZIP 版
WorkMonitor.zip		インストールしたくない人、USB メモリで持ち歩きたい人展開して、中の WorkMonitor.exe をダブルクリックするだけです。

初めて開くと「Windows によって PC が保護されました」と出ることがあります。個人が作った、署名のないアプリのためです。詳細情報 → 実行 の順に押すと起動できます。

心配な場合は、リリースに付いている SHA256SUMS.txt の値と、ダウンロードしたファイルの SHA-256 が同じかを確かめてください（PowerShell で Get-FileHash ファイル名）。

2はじめの設定

入れたらすぐに記録が始まります。次の3つだけ決めておくと便利です。どれもメイン画面の ⚙ 設定 から変えられます。

  1. 1日の目標を決める（一般）
    初期は 3 時間です。0 にすると目標なしになります。
  2. 数えたくないアプリを外す（アプリ別）
    ゲームや動画サイトなどを「作業に数えない」にします。逆に「選んだアプリだけ数える」方式にもできます（アプリ別の設定）。
  3. Windows の起動時に自動で起動する（一般）
    オンにすると、毎回起動しなくても記録が続きます。

ウィンドウを閉じても、アプリは画面右下のタスクトレイで記録を続けます。完全に終わらせるときは、トレイのアイコンを右クリックして 終了 を選びます。

4作業時間の数え方

WorkMonitor は 1秒ごとに、最後にキーボードやマウスを操作した時刻と、前面にあるアプリを調べます。

  • 操作している間だけ数えます。最後の操作から一定の秒数（初期は 60秒）たつと「休憩中」になり、時間が止まります。休憩中になったときは、最後に操作した時刻までさかのぼって数えるので、放置した時間は入りません。
  • 前面のアプリで判断します。「数えない」にしたアプリが前面にあるときは、操作していても数えません。
  • WorkMonitor 自身、Python、Windows の機能（スタートメニュー、検索、設定、エクスプローラーなど）は、最初から数えない設定です。
  • ブラウザは、サイトの名前ごとにまとめて記録します（ページのタイトルが変わるたびに別の作業にはなりません）。

動画を見ながらメモを取る、資料を読む時間が長い、など操作が少ない作業が多い人は、設定 → 一般 → 無操作で「休憩中」にするまでの秒数 を長め（120〜300 秒など）にしてください。

5アプリ別の設定

設定 → アプリ別 で、アプリごとに次のことを決められます。一覧には、これまでに使ったアプリが出ます。一覧にないアプリは、下の欄に exe の名前（例: notepad.exe）を入れて追加できます。

項目内容
表示名グラフや一覧に出る名前（例: Code.exe → 「VS Code」）。
カテゴリ「開発」「ブラウザ」「資料作成」「デザイン」「コミュニケーション」など。新しいカテゴリも作れます。ダッシュボードでカテゴリ別に集計できます。
作業に数えるオフにすると、そのアプリを使っている時間は作業時間に入りません。
Discord の表示そのアプリを使っているときに Discord に出す文（例:「プログラミング中」）。空なら「作業中」。

作業時間に含めるアプリの決め方（2つの方式）

  • 「数えない」にしたアプリ以外すべて（初期）… ほとんどのアプリを数え、ゲームなどを外していく方式。
  • 選んだアプリだけ … 「作業に数える」をオンにしたアプリだけを数える方式。仕事用のアプリが決まっている人向け。何も選んでいないと、何も数えないので注意してください。

どちらの方式でも、変えた設定は過去の集計にも反映されます（記録そのものは変わりません）。

6目標と通知

  • 1日の目標（設定 → 一般、初期 3 時間）を達成すると、通知でお知らせします（1日1回）。
  • 連続達成：目標を達成した日が続くと 🔥 の日数が増えます。
  • 先週のまとめ：週が変わって最初に起動したとき、先週の作業時間と、前の週との比較を通知します。
  • 通知は Windows の通知に出ます。出ない場合は、Windows の 設定 → システム → 通知 で WorkMonitor（または Python）の通知がオンか確かめてください。

7ダッシュボード

メイン画面の 📊 ダッシュボード を押すと、この PC の記録をグラフにしたページがブラウザで開きます（インターネットにはつながず、PC の中だけで作ります）。

  • 日・週・月を切り替えられます。週と月は、前の週・前の月との比較も出ます。
  • アプリ別・カテゴリ別を切り替えられます。
  • 日の表示では、時間帯別のグラフ（何時ごろに作業したか）も出ます。
  • 直近の日別の作業時間と、アプリ別・カテゴリ別の内訳の表が出ます。

別の PC やスマホから見たいときは、ウェブで記録を見る を使ってください。

8オーバーレイ

画面の端に、小さなタイマーを常に表示します。ゲームや全画面の作業中でも作業時間が見えます。メイン画面の 🪟 オーバーレイ で表示／非表示を切り替えます。

  • ドラッグで移動、右クリックでメニュー（メイン画面を開く・設定・閉じる）、ダブルクリックでメイン画面を開きます。
  • 設定 → オーバーレイ で、透明度・大きさ（小・中・大）・アプリ名の表示・クリックの透過を変えられます。
  • クリックの透過をオンにすると、オーバーレイの後ろのウィンドウを操作できます（その間はドラッグできません）。
  • 見失ったときは 位置を初期化（右上へ） を押してください。

9Discord に表示

Discord のプロフィールに「作業中 1:23:45 経過」のように表示できます（Rich Presence）。

  1. Discord Developer Portal を開き、New Application でアプリを作ります。付けた名前が「〇〇をプレイ中」として表示されます（例: 「作業」）。
  2. 表示された Application ID（数字）をコピーします。
  3. WorkMonitor の 設定 → Discord に貼り付けて、保存 を押します。
  4. PC 版の Discord アプリを起動しておきます（ブラウザ版の Discord では表示されません）。
  • Discord の表示にアプリ名を入れる をオンにすると「作業中: VS Code」のようになります。フレンドに見えるので注意してください。
  • アプリごとの文言は アプリ別の設定 で変えられます。
  • いまの状態は、メイン画面の下や 設定 → Discord に出ます。

10アカウントと同期

アカウントを作ると、記録がクラウドに同期され、スマホや別の PC のブラウザからも見られます。アカウントがなくても、アプリの機能はすべて使えます。

  1. 設定 → アカウント でメールアドレスとパスワード（8文字以上）を入れ、利用規約とプライバシーポリシーに同意して 新しく登録 を押します。
  2. 届いた確認メールのリンクを開きます。
  3. アプリに戻って ログイン します。これまでの記録（最大120日分）が送られ、その後は5分ごとに同期されます。

送るもの・送らないもの

  • 送るのは 日ごと・アプリごとの合計時間、カテゴリ、目標 だけです。ウィンドウのタイトル（開いているファイル名やページ名）は送りません。
  • 送る前に、PC の中で AES-256-GCM で暗号化します（エンドツーエンド暗号化）。鍵はパスワードから作るので、サーバーの管理者も中身を読めません。

暗号の鍵はパスワードから作るため、パスワードを忘れて再設定すると、クラウドの記録は読めなくなり、作り直しになります。アプリで再びログインすると、PC に残っている記録（最大120日分）を送り直します。

同期を止めたいときは、記録をクラウドに同期する をオフにします。今すぐ同期 でいつでも送れます。

11ウェブで記録を見る

  1. 公式サイトの ログイン を開きます（アプリの 🌐 ウェブで見る からも開けます）。
  2. アプリと同じメールアドレスとパスワードでログインします。パスワードはこのブラウザの中で鍵を作るのに使い、サーバーには送りません。
  3. 日・週・月、アプリ別・カテゴリ別のグラフと表が見られます。
  • この端末で暗号鍵を記憶する をオンにすると、次からパスワードを入れずに見られます。共用の PC ではオフにしてください。ログアウトすると鍵は消えます。
  • パスワードを忘れたときは、ログイン画面の パスワードを忘れた場合 から再設定できます（上の注意を読んでください）。

12記録・アカウントの削除

やりたいこと場所消えるもの
記録だけ消す（アカウントは残す）アプリ: 設定 → 一般 → 記録をすべて削除
サイト: 記録を見るページの下		この PC の記録 と／または クラウドの記録（選べます）。設定とアカウントは残ります。
アカウントを消すアプリ: 設定 → アカウント → アカウントを削除
サイト: 記録を見るページの下		アカウント・クラウドの記録・暗号鍵・同意の記録。PC の記録は残ります。

どちらも元に戻せないため、間違えて消さないよう、次の手順を踏んだときだけ実行されます。

  1. 決まった文を、自分で入力します（貼り付けはできません）。記録は delete workmonitor alldata、アカウントは delete workmonitor account。
  2. 内容を理解し、削除に同意します にチェックを入れます。
  3. 5 秒待つと、ボタンが押せるようになります。
  4. ボタンを 3 回押すと削除されます。

クラウドの記録だけを消した場合、そのままでは次の同期で PC の記録がまた送られるため、クラウド同期は自動でオフになります。

13MOD を入れる

MOD は、WorkMonitor に機能を足す追加プログラムです（ポモドーロタイマー、目標カレンダー、日報の自動作成など）。公式サイトの MOD に、みんなが作った MOD が公開されています。

いちばんかんたんな方法：MOD ストア 1.8.0〜

  1. メイン画面の ⚙ 設定 → Mods → 🧩 MOD ストア を開きます。
  2. 検索や、左の「まだ入れていない／入れている／更新がある」で MOD を探します。カードを押すと、右に説明と「この MOD が行うこと」が出ます。
  3. 入れる を押すだけで入って、すぐに動き始めます。初めて使うときだけ、自己責任についての確認が出ます。

サイトからダウンロードして入れる方法

  1. MOD のページ で MOD を探し、ダウンロード します（.py か .zip）。
  2. ダウンロードしたファイルを、WorkMonitor のメイン画面か 設定 → Mods にドラッグ＆ドロップします（ファイルから追加… でも選べます）。
  3. 確認が出たら はい を押します。

MOD は利用者が作ったプログラムで、アプリと同じ権限で動きます。公開前に自動審査をしていますが、安全を保証するものではありません。「中身を見る」で内容を確かめ、信頼できるものだけ入れてください。MOD の利用は自己責任です（利用規約 第8条）。

「WorkMonitor 1.7.0 以降が必要」などと書かれた MOD は、そのバージョン以降で使えます。古いと MOD ストアのボタンが押せません。

14MOD の管理と自動更新

設定 → Mods で、入れた MOD を管理できます。オン・オフはすぐに反映されます。

  • オン／オフ：一覧で選んで オンにする／オフにする。
  • 再読み込み：MOD のファイルを直したときに、アプリを再起動せずに読み込み直します。
  • 削除：MOD のファイルを消します（MOD が保存したデータは残ります）。
  • ログ：選んだ MOD のメッセージやエラーが下の欄に出ます。MOD の中でエラーが続くと、その MOD は自動で止まります。
  • MOD のボタン：MOD によっては、選ぶとその MOD の操作ボタン（「タイマーをリセット」など）が出ます。
  • MOD を読み込む をオフにすると、すべての MOD を止められます。

更新と自動更新 1.8.0〜

  • MOD ストアの 更新がある に、新しいバージョンが出た MOD が出ます。更新 か すべて更新 を押します。
  • ストアから入れた MOD を自動で更新する をオンにすると、起動したときと1日1回、自動で新しいバージョンを入れます（初期はオフ）。対象は MOD ストアから入れた MOD だけです。
  • 更新しても、MOD のオン・オフと MOD が保存したデータはそのまま残ります。
  • ダウンロードしたファイルは、公開一覧の SHA-256 と同じか確かめてから入れます。違えば入れません。

MOD のせいでアプリが起動しなくなったら、WorkMonitor.exe --no-mods で起動すると、MOD を読み込まずに起動できます（ショートカットのプロパティの「リンク先」の最後に --no-mods を足すなど）。そのあと 設定 → Mods で原因の MOD をオフにするか削除してください。

15MOD を作る・投稿する

MOD はふつうの Python のプログラムです。setup(api) という関数を書くと、アプリが起動したとき（MOD をオンにしたとき）に呼ばれます。

MOD_INFO = {
    "name": "はじめての MOD",
    "version": "1.0.0",
    "author": "あなたの名前",
    "description": "作業を始めたら通知します。",
}

def setup(api):
    @api.on("state_change")
    def changed(old, new, status):
        if new == "working":
            api.notify(f"{status['app_name']} で作業を始めました")
  • このファイルを my_first_mod.py として保存し、メイン画面にドラッグ＆ドロップすると動きます。
  • イベント（作業中になった、目標を達成した など）、メイン画面への表示、オーバーレイや Discord の文字の変更、通知、データの保存などができます。
  • 詳しい作り方は、設定 → Mods → 作り方 で開く modreadme.txt か、GitHub の modreadme.txt を見てください。作例（ポモドーロタイマーなど）もあります。

公式サイトに投稿する

  1. MOD のページ → 投稿・更新 を開き、WorkMonitor のアカウントでログインします。
  2. ファイル（.py か .zip）を選び、利用規約 第8条に同意して 投稿する を押します。ファイル名がそのまま MOD の名前になります（英小文字・数字・_・- で 2〜40 文字）。
  3. 10〜20 分ほどで自動審査が終わります。合格すると公開され、MOD ストアにも出ます。不合格のときは、理由が「あなたの MOD」に出ます。

更新するときは、MOD_INFO の version を上げて同じファイル名で投稿します（あなたの MOD → 新しいバージョンを投稿）。更新できるのは、最初に公開した人だけです。

自動審査では、投稿されたファイルを実行せずに中身を調べます。ほかのプログラムの起動、組み立てたコードの実行、ファイルの削除、パスワードやトークンの読み取りなどは不合格になります。通信やファイルの書き込みなどは、一覧に「この MOD が行うこと」として表示されます。

17タスクトレイ・自動起動

  • メイン画面の × を押しても終了せず、タスクトレイ（画面右下）で記録を続けます。
  • トレイのアイコンを右クリックすると、開く・ダッシュボード・ウェブで見る・オーバーレイ・設定・Mods・アップデートを確認・終了 が選べます。ダブルクリック（クリック）でメイン画面が開きます。
  • アイコンが見当たらないときは、トレイの ^（隠れているアイコン）の中を見てください。
  • 設定 → 一般 → Windows の起動時に自動で起動する をオンにすると、ログインしたときに最小化した状態で起動します。
  • WorkMonitor は二重には起動しません。「すでに起動しています」と出たら、トレイのアイコンから開いてください。

18アップデート

  • 新しいバージョンが出ると、メイン画面の上にお知らせが出て、通知も届きます（1日1回確認。設定 → 一般 でオフにできます）。
  • インストーラー版：新しい WorkMonitor-Setup.exe をダウンロードして実行すると、上書きで更新されます。
  • ZIP 版：アプリを終了してから、WorkMonitor.exe を新しいものに入れ替えます。
  • 記録・設定・MOD はそのまま引き継がれます。

19データの場所・バックアップ

記録と設定は %APPDATA%\WorkMonitor に保存されます（設定 → 一般 → 記録フォルダを開く で開けます）。

場所中身
logs\日付.csv作業の記録（開始・終了時刻、秒数、アプリ、ウィンドウのタイトル）。Excel で開けます。
config.json設定
apps.jsonこれまでに使ったアプリの一覧
session.binログイン情報（この PC のユーザーだけが読めるよう暗号化）
mods\ ／ mod_data\入れた MOD と、MOD が保存したデータ
  • バックアップ：このフォルダごとコピーしておけば、別の PC に移すこともできます（session.bin は移せないので、移した先でログインし直してください）。
  • アンインストール：インストーラー版は Windows の 設定 → アプリ から。ZIP 版はフォルダを消すだけです。どちらも記録は残るので、要らなければ上のフォルダも消してください。

20困ったとき

作業時間が増えない
  • 状態が「数えないアプリを使用中」（オレンジ）なら、そのアプリが数えない設定です。設定 → アプリ別 で「作業に数える」をオンにしてください。
  • 「選んだアプリだけ」方式で、数えるアプリを1つも選んでいないと、何も数えません。
  • 状態が「休憩中」（灰色）のままなら、操作していない扱いです。休憩中にするまでの秒数を長くしてみてください。
  • 管理者として起動したアプリ（一部のゲームなど）が前面にあると、アプリの名前を読み取れず「(不明)」になることがあります。WorkMonitor も管理者として起動すると読み取れます。
Discord に表示されない
  • PC 版の Discord アプリが起動しているか確かめてください（ブラウザ版では出ません）。
  • 設定 → Discord の Application ID が正しいか、「Discord に作業時間を表示する」がオンか確かめてください。
  • Discord の ユーザー設定 → アクティビティのプライバシー で「現在のアクティビティをステータスに表示する」がオンか確かめてください。
同期できない・「利用規約への同意が必要」と出る
  • 利用規約が新しくなったときは、もう一度同意が必要です。設定 → アカウント で「同意する」にチェックを入れてログインし直してください。
  • サイトで「新しい利用規約への同意を確認できませんでした」と出るときは、一度ログアウトしてログインし直してください。
  • インターネットにつながっているか、メールアドレスの確認が済んでいるか確かめてください。
ウェブで記録が出ない・暗号を解除できない
  • アプリでログインして同期がオンになっているか確かめてください（今すぐ同期 を押すとすぐ送れます）。
  • パスワードを再設定した場合、古い記録は読めません。アプリでログインし直すと、PC の記録から送り直されます。
MOD を入れたらおかしくなった・起動しない
  • 設定 → Mods で、その MOD を選んでログを確かめ、オフにするか削除してください。
  • 起動しない場合は WorkMonitor.exe --no-mods で起動するか、%APPDATA%\WorkMonitor\mods からその MOD のファイルを消してください。
  • 問題のある MOD は、GitHub の Issues でお知らせください。
「Windows によって PC が保護されました」と出る

署名のない個人開発のアプリのため表示されます。詳細情報 → 実行 で起動できます。ファイルが本物か心配なときは、インストール の SHA-256 の確かめ方を見てください。

通知が出ない

Windows の 設定 → システム → 通知 で通知がオンか、集中モード（応答不可）になっていないか確かめてください。

画面がぼやける・文字が大きすぎる／小さすぎる

Windows の表示スケール（設定 → ディスプレイ → 拡大縮小）に合わせて表示します。スケールを変えたら、アプリを一度終了して起動し直してください。
