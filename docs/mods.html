MOD

WorkMonitor に機能を足す MOD を探してダウンロードしたり、自分で作った MOD を投稿したりできます。

⚠ MOD の利用は自己責任です。 ここにある MOD は利用者が作って投稿したもので、運営者が作ったものではありません。公開前に自動審査で危険な書き方がないかを調べていますが、 自動審査ですべての問題を見つけられるわけではなく、安全や動作は保証できません。MOD はアプリと同じ権限で動くプログラムです。 内容を確認し、信頼できるものだけ入れてください。MOD の利用で生じた損害について、運営者は責任を負いません （利用規約 第8条）。ダウンロードした時点で、この内容に同意したものとみなします。

入れ方

  1. WorkMonitor を 1.6.0 以降にします（ダウンロード）。
  2. 上の一覧から MOD をダウンロードします（.py か .zip）。
  3. ダウンロードしたファイルを、WorkMonitor のメイン画面か「設定 → Mods」にドラッグ＆ドロップします。
  4. 確認が出たら「はい」を押すと、すぐに動き始めます。オン・オフや削除は「設定 → Mods」でできます。

MOD を投稿する

投稿した MOD は自動で審査され、問題がなければ GitHub に置かれて、この一覧からダウンロードできるようになります（10〜20 分ほどかかります）。

投稿するには、WorkMonitor のアカウントでログインしてください。

ログイン・登録

ログインしたあと、このページ（上のメニューの「MOD」）に戻ってください。

利用規約が新しくなりました。投稿するには、新しい利用規約とプライバシーポリシーへの同意が必要です。

投稿のきまり
  • ファイル名がそのまま MOD の名前になります。英小文字・数字・_・- で 2〜40 文字にしてください（例: my_timer.py）。
  • MOD_INFO に name・version・author・description を書いてください。author と説明は公開されます。
  • 同じ名前の MOD を更新できるのは、最初に公開した人だけです。更新するときは version を上げてください。
  • ほかのプログラムの起動、組み立てたコードの実行、ファイルの削除、パスワードやトークンの読み取り、api.app の利用などは、自動審査で不合格になります。詳しくは modreadme.txt の「12. 公式サイトへの投稿」を見てください。
  • 通信やファイルの書き込みなどをする MOD は、その内容が一覧に表示されます。
  • 審査中は 3 件まで、1 日に 10 件まで投稿できます。
