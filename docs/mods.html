投稿・更新

投稿した MOD は自動で審査され、問題がなければ GitHub に置かれて、「MOD を探す」からダウンロードできるようになります（10〜20 分ほど）。

投稿するには、WorkMonitor のアカウントでログインしてください。

ログイン・登録

利用規約が新しくなりました。投稿するには、新しい利用規約とプライバシーポリシーへの同意が必要です。

投稿のきまり
  • ファイル名がそのまま MOD の名前になります。英小文字・数字・_・- で 2〜40 文字にしてください（例: my_timer.py）。
  • MOD_INFO に name・version・author・description を書いてください。author と説明は公開されます。
  • 更新：MOD_INFO の version を上げて、同じファイル名で投稿します（「あなたの MOD」の「新しいバージョンを投稿」からもできます）。更新できるのは最初に公開した人だけです。
  • ほかのプログラムの起動、組み立てたコードの実行、ファイルの削除、パスワードやトークンの読み取り、api.app の利用などは、自動審査で不合格になります。詳しくは modreadme.txt の「12. 公式サイトへの投稿」を見てください。
  • 通信やファイルの書き込みなどをする MOD は、その内容が一覧に表示されます。
  • 審査中は 3 件まで、1 日に 10 件まで投稿できます。結果は「あなたの MOD」に出ます。

入れ方・注意

MOD の入れ方
  1. WorkMonitor を 1.6.0 以降にします（ダウンロード）。「WorkMonitor 1.7.0 以降が必要」と書かれた MOD は 1.7.0 以降で使えます。
  2. かんたんな方法（WorkMonitor 1.8.0 以降）：アプリの「設定 → Mods → 🧩 MOD ストア」で MOD を選んで「入れる」を押すだけです。「ストアから入れた MOD を自動で更新する」をオンにすると、新しいバージョンが自動で入ります（初期はオフ）。以下は、サイトからダウンロードして入れる方法です。
  3. 「MOD を探す」から MOD をダウンロードします（.py か .zip）。
  4. ダウンロードしたファイルを、WorkMonitor のメイン画面か「設定 → Mods」にドラッグ＆ドロップします。
  5. 確認が出たら「はい」を押すと、すぐに動き始めます。オン・オフや削除は「設定 → Mods」でできます。
  6. 新しいバージョンが出たら、同じようにドラッグ＆ドロップすると上書きで更新できます（MOD が保存したデータは残ります）。
⚠ MOD の利用は自己責任です。

ここにある MOD は利用者が作って投稿したもので、運営者が作ったものではありません。公開前に自動審査で危険な書き方がないかを調べていますが、 自動審査ですべての問題を見つけられるわけではなく、安全や動作は保証できません。MOD はアプリと同じ権限で動くプログラムです。 「中身を見る」で内容を確認し、信頼できるものだけ入れてください。MOD の利用で生じた損害について、運営者は責任を負いません （利用規約 第8条）。ダウンロードした時点で、この内容に同意したものとみなします。

カードの見方
  • ✓ 自動審査済み … 公開前の自動審査に合格しています。
  • インターネットに接続します など … 自動審査で分かった、その MOD が行うことです。
  • WorkMonitor 1.7.0 以降が必要 … 古いバージョンでは使えません。
  • 「詳しい情報」の SHA-256 は、ダウンロードしたファイルが改ざんされていないかを確かめるためのものです。
