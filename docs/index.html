手を動かした時間だけを、
正確に記録する。

WorkMonitor は、キーボードやマウスを操作している時間だけを数える Windows 用の作業時間トラッカーです。 アプリを開いたまま放置した時間は数えません。

できること

「パソコンの前にいた時間」ではなく「実際に作業した時間」がわかります。

⌨️

操作した時間だけ数える

一定時間（初期値 60 秒）操作がないと、自動で「休憩中」になります。

🎯

1日の目標と連続記録

目標までの残り時間を表示し、達成したら通知。連続で達成した日数も数えます。

🗂️

アプリ別・カテゴリ別

アプリごとに「作業に数えるか」やカテゴリを設定。ゲームや動画は数えない、などができます。

📊

日・週・月のレポート

前の週や前の月と比べたグラフで、作業の増減がひと目でわかります。

☁️

ウェブでも見られる

ログインすると記録が同期され、スマホや別の PC のブラウザからも確認できます。データはエンドツーエンドで暗号化されます。

🪟

オーバーレイと Discord

画面の端に常にタイマーを表示。Discord のプロフィールに作業時間を出すこともできます。

  • 管理者の権限は不要です

  • USB メモリなど好きな場所に置けます

はじめ方

  1. ダウンロードして起動
    「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください（署名のない個人開発アプリのため表示されます）。
  2. そのまま作業する
    ウィンドウを閉じてもタスクトレイで記録を続けます。アイコンが緑なら作業中です。
  3. ウェブでも見たいときはログイン
    アプリの「設定 → アカウント」で登録・ログインすると、このサイトの「ログイン」から記録を見られます。

よくある質問

どんなデータが送られますか？

記録は基本的に PC の中だけに保存されます。ログインして同期をオンにした場合だけ、「日ごと・アプリごとの合計時間」「カテゴリ」「目標」をサーバーに送ります。ウィンドウのタイトル（開いているファイル名やページ名）は送りません。

サーバーに送ったデータは安全ですか？

送る前に PC の中で AES-256-GCM で暗号化する「エンドツーエンド暗号化」です。暗号の鍵はパスワードから PBKDF2（60万回）で作り、サーバーには暗号文しか置きません。サーバーの管理者でも中身（アプリ名・時間など）は読めません。このサイトで見るときも、復号はあなたのブラウザの中だけで行います。通信自体も TLS（HTTPS）で暗号化しています。

そのため、パスワードを忘れて再設定すると、クラウドの記録は読めなくなり作り直しになります（アプリが PC の記録から最大120日分を送り直します）。

アカウントを削除できますか？

できます。このサイトの「ログイン」で記録を表示した画面の下、またはアプリの「設定 → アカウント」から、いつでも削除できます。クラウドの記録・暗号鍵もすぐに削除されます（PC の記録は残ります）。詳しくはプライバシーポリシーをご覧ください。

無料ですか？

無料です。ソースコードは GitHub で公開しています（MIT ライセンス）。

アップデートはどうすればいいですか？

新しいバージョンが出るとアプリ内でお知らせします。このページから最新版をダウンロードして、インストーラー版は上書きインストール、ZIP 版は exe を入れ替えてください。記録と設定は引き継がれます。

Mac や Linux でも使えますか？

今のところ Windows 10 / 11 専用です。記録の閲覧はこのサイトからどの端末でもできます。
