WorkMonitor - 作業時間を記録するツール（Windows 10/11）
==========================================================
ウェブサイト: https://kaikomziu.github.io/WorkMonitor/

■ できること
・キーボードやマウスを操作している時間だけを「作業時間」として記録します。
  画面を開いたまま放置している時間は数えません。
・1日の目標を決めると、進み具合を表示し、達成したら通知します（連続達成日数も表示）。
・週・月ごとのレポートで、前の週や前の月と比べられます。
・アプリごとに「作業に数えるか」を決められます（ゲームや動画は数えない、など）。
  WorkMonitor 自身・Python・Windows の機能（スタートメニューや検索など）は最初から数えません。
・アプリを「開発」「資料作成」などのカテゴリに分けて、表やグラフで確認できます。
・ログインすると記録が同期され、ウェブサイトからスマホや別の PC でも見られます。
・ライト／ダークテーマを切り替えられます。
・画面の端に小さなタイマー（オーバーレイ）を常に表示できます。
・Discord のプロフィールに「作業中 1:23:45 経過」のように表示できます。
  アプリごとに「プログラミング中」「お絵かき中」など文言を変えられます。
・新しいバージョンが出たらお知らせします。
・MOD（Python で書いた追加機能）を入れられます（MOD ローダー「Earo」）。

■ 使い方
1. インストーラー版はスタートメニューの「WorkMonitor」から、
   ZIP 版は WorkMonitor.exe をダブルクリックして起動します。
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）
2. ウィンドウを閉じても、画面右下のタスクトレイで記録を続けます。
   アイコンが緑なら作業中、灰色なら休憩中、オレンジなら数えないアプリを使用中です。
3. 「ダッシュボード」ボタンで、日・週・月ごとのグラフを表示します。
4. 「オーバーレイ」ボタンで、画面の端にタイマーを表示します。
   ドラッグで移動、右クリックでメニュー、ダブルクリックでメイン画面を開きます。
5. 終了するときは、タスクトレイのアイコンを右クリックして「終了」を選びます。

■ 設定（「設定」ボタン）
・一般 …… 1日の目標／休憩中にするまでの秒数（初期値 60 秒）／自動起動／最前面表示／テーマ／アップデートの確認
・アプリ別 …… 表示名／カテゴリ／作業に数えるか／Discord に出す文言
・オーバーレイ …… 表示／透明度／大きさ／アプリ名の表示／クリックの透過
・Discord …… 表示する／Application ID／アプリ名も表示する
・アカウント …… 登録／ログイン／同期のオン・オフ／ログアウト
・Mods …… MOD の追加／オン・オフ／再読み込み／削除／エラーのログ

■ MOD
・.py ファイル・フォルダ・.zip の MOD を、メイン画面か「設定 → Mods」にドラッグ＆ドロップすると追加できます。
・作り方は modreadme.txt（%APPDATA%\WorkMonitor\mods にもあります）を見てください。
・MOD はこのアプリと同じ権限で動くプログラムです。信頼できる人が作ったものだけ入れてください。
・MOD のせいで起動できなくなったら、WorkMonitor.exe --no-mods で起動すると MOD を読み込みません。

■ Discord に表示するには
1. https://discord.com/developers/applications で「New Application」を作成
   （ここで付けた名前が「〇〇をプレイ中」と表示されます）
2. 「Application ID」をコピーして、設定画面に貼り付けて保存
3. PC 版の Discord アプリを起動しておく（ブラウザ版では表示されません）

■ 記録の保存場所と送信するデータ
%APPDATA%\WorkMonitor（設定画面の「記録フォルダを開く」から開けます）
・logs\日付.csv … 作業の記録（Excel で開けます）
・config.json … 設定
記録は基本的にこの PC の中だけに保存されます。外部と通信するのは次の場合だけです。
・ログインして同期がオンのとき：日ごと・アプリごとの合計時間、カテゴリ、目標を送信
  （ウィンドウのタイトルは送りません）
  送る前に PC の中で AES-256-GCM で暗号化します（エンドツーエンド暗号化）。
  サーバーには暗号文しか残らず、鍵はパスワードから作るのでサーバーの管理者も中身を読めません。
  そのため、パスワードを再設定するとクラウドの記録は作り直しになります
  （この PC の記録から最大120日分を送り直します）。
・Discord 表示がオンのとき：作業中／休憩中と時間を Discord に表示
・アップデートの確認がオンのとき：1日に1回 GitHub に最新版の番号を問い合わせ

■ アンインストール
・インストーラー版：Windows の「設定 → アプリ」から WorkMonitor をアンインストール
・ZIP 版：設定で「自動で起動する」をオフにして保存 → タスクトレイから終了 → WorkMonitor.exe を削除
・記録も消す場合は %APPDATA%\WorkMonitor フォルダを削除
